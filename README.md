# Trota

Landing page for Trota, built with [Next.js](https://nextjs.org) (App Router), Tailwind CSS and Lenis.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Copy lives in `src/locales` (`en`, `si`, `ta`).
- Team photos live in `public/images` (`nikesh`, `savitha`, `asri`, `sayumi`, `isuli` `.webp`).
- `npm run flowers` regenerates the scribbled flowers in `src/lib/flowers.json` and the favicon.
